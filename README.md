# LiveEdit

사설망에서 Obsidian 노트를 함께 편집합니다.
**플러그인을 켠 현재 볼트 전체를 공유합니다. 폴더·방 코드·방장 인증 키 입력은 없습니다.**

## 업데이트

이번 **0.7.0은 플러그인과 서버를 모두 교체**해야 합니다.
- 플러그인: BRAT에서 업데이트하거나 릴리스의 플러그인 ZIP을 설치합니다.
- 서버: 기존 서버 창을 닫고 새 서버 ZIP을 풉니다. 기존 `data` 폴더는 옮겨둡니다. 서버 PC에는 Node.js 20 이상이 필요합니다.

[최신 버전 다운로드](https://github.com/drkim-dev/liveedit/releases/latest)

## 방장 — 먼저 방을 여세요

1. 서버 PC에서 **`start.cmd`를 더블클릭**합니다. 열린 창은 그대로 둡니다.
2. 같은 PC의 Obsidian에서 **설정 → LiveEdit → 방장**을 선택합니다.
3. 서버 주소는 기본값 **`ws://localhost:1234`**로 둡니다.
4. **이름을 입력**하고 **방 개설하기**를 누릅니다.
5. 팀원에게 이 PC의 접속 주소를 알려줍니다. 예: `ws://192.168.0.10:1234`

종료할 때는 **방 닫기**를 누릅니다. 방장이 열기 전에는 참여할 수 없습니다.

## 참여자 — 주소를 넣고 참여하세요

1. LiveEdit에서 **참여자**를 선택합니다.
2. 방장이 알려준 **서버 주소**를 입력합니다.
3. **이름을 입력**하고 **참여하기**를 누릅니다. 최신 노트를 받으면 편집할 수 있습니다.

## 누가 어디서 쓰는지 보기

왼쪽 **LiveEdit 참여자** 탭에서 본인을 포함한 접속자, 현재 노트와 행 번호, 작성 상태를 확인합니다.
노트 이름을 누르면 그 위치로 이동합니다. 탭이 안 보이면 왼쪽 사람 모양 아이콘을 누르세요.
색상은 접속자끼리 겹치지 않게 자동 배정됩니다. 이름 변경 시에는 다시 접속합니다.

## 사용 규칙

- 연결과 동기화가 끝나면 함께 편집·생성·삭제·이름 변경할 수 있습니다.
- 연결이 끊기거나 방이 닫히면 현재 볼트는 **읽기 전용**입니다.
- 재접속하면 최신 공용 상태를 받은 뒤 편집할 수 있습니다.
- 개인 작업은 **다른 볼트**에서 하세요.
- 로컬 내용이 공용 내용과 다르면 `.liveedit-backups`에 사본을 남깁니다.
- 마크다운 노트만 동기화합니다. 첨부파일과 캔버스는 제외합니다.

## 연결이 안 되면

- 방장: `start.cmd`로 연 서버 창이 켜져 있는지 확인하세요.
- 참여자: 방장이 **방 개설하기**를 눌렀는지, 서버 주소가 맞는지 확인하세요.
- 서로 다른 PC라면 같은 사설망/VPN에 있어야 하고 서버 PC의 방화벽에서 해당 포트(기본 1234)를 허용해야 합니다.
