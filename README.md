# LiveEdit

사설망에서 Obsidian 노트를 함께 편집합니다.
**플러그인을 켠 현재 볼트 전체를 공유합니다. 폴더·방 코드·방장 인증 키 입력은 없습니다.**

## 업데이트

**방장·참여자 플러그인과 서버를 모두 0.9.0으로 업데이트**하세요. 서버를 먼저 바꾸고 방장이 방을 연 뒤 참여자가 접속하세요.
- 플러그인: BRAT에서 업데이트하거나 릴리스의 플러그인 ZIP을 설치합니다.
- 서버: 기존 서버 창을 닫고 새 서버 ZIP을 풉니다. 기존 `data` 폴더 **전체**를 옮깁니다. 서버 PC에는 Node.js 20 이상이 필요합니다.

[최신 버전 다운로드](https://github.com/drkim-dev/liveedit/releases/latest)

## 방장 — 먼저 방을 여세요

1. 서버 PC에서 **`start.cmd`를 더블클릭**합니다. 열린 창은 그대로 둡니다.
2. 같은 PC의 Obsidian에서 **설정 → LiveEdit → 방장**을 선택합니다.
3. 서버 주소는 기본값 **`ws://localhost:1234`**로 둡니다.
4. **이름을 입력**하고 **방 개설하기**를 누릅니다.
5. 팀원에게 이 PC의 접속 주소를 알려줍니다. 예: `ws://192.168.0.10:1234`

종료할 때는 **방 닫기**를 누릅니다. 방장이 열기 전에는 참여할 수 없습니다.

## 참여자 — 주소를 넣고 참여하세요

1. LiveEdit에서 **참여자**를 선택합니다.
2. 방장이 알려준 **서버 주소**를 입력합니다.
3. **이름을 입력**하고 **참여하기**를 누릅니다. 최신 노트를 받으면 편집할 수 있습니다.

## 누가 어디서 쓰는지 보기

왼쪽 **파일 목록의 노트 이름 옆**에 그 노트를 열어둔 사람의 이름과 색상이 표시됩니다.
작성 중/보는 중은 구분하지 않습니다. 여러 명이면 이름을 함께 표시하고, 공간이 부족하면 `+인원수`로 줄입니다. 마우스를 올리면 전체 이름을 볼 수 있습니다.
폴더를 접으면 안쪽 노트를 열어둔 사람들이 **접힌 폴더 옆**에 표시됩니다. 펼치면 각 노트 옆으로 돌아갑니다. 접힌 폴더에 마우스를 올리면 사람별 노트 경로도 확인할 수 있습니다.
전체 참여자 목록은 아래 상태 표시줄이나 사람 모양 아이콘을 누르세요.
색상은 접속자끼리 겹치지 않게 자동 배정됩니다. 이름 변경 시에는 다시 접속합니다.

## 사용 규칙

- 연결과 동기화가 끝나면 함께 편집·생성·삭제·이름 변경할 수 있습니다. 빈 폴더의 생성·삭제와 폴더 이름 변경도 연동됩니다.
- 삭제된 폴더는 재접속할 때도 정리합니다. 다만 공유되지 않는 PDF 등의 첨부파일·숨김 파일이 남아 있는 폴더는 보존합니다.
- 연결이 끊기거나 방이 닫히면 현재 볼트는 **읽기 전용**입니다.
- 재접속하면 최신 공용 상태를 받은 뒤 편집할 수 있습니다.
- 개인 작업은 **다른 볼트**에서 하세요.
- 로컬 내용이 공용 내용과 다르면 `.liveedit-backups`에 사본을 남깁니다.
- 노트에 사진을 붙여넣거나 드래그하면 **누가 추가하든 다른 사람에게 자동으로 전달**됩니다. 따로 사진을 보낼 필요가 없습니다.
- 기존 방장의 사진과 새로 접속한 사람에게 필요한 사진도 같은 경로로 복사합니다. 사진 삭제·이름 변경·폴더 이동도 연동됩니다.
- 사진 형식: PNG, JPG/JPEG, GIF, WebP, AVIF, BMP, SVG. 한 장 20MB까지 공유합니다. **방 전체 64MB 제한은 없습니다.** 사진은 서버 `data/images`에 따로 저장하며, 새 참여자는 필요한 사진을 하나씩 받습니다. 0.8.0의 사진은 서버가 자동으로 이전합니다.
- 사진을 제외한 첨부파일(PDF 등)과 캔버스는 동기화하지 않습니다.

## 연결이 안 되면

- 방장: `start.cmd`로 연 서버 창이 켜져 있는지 확인하세요.
- 참여자: 방장이 **방 개설하기**를 눌렀는지, 서버 주소가 맞는지 확인하세요.
- 서로 다른 PC라면 같은 사설망/VPN에 있어야 하고 서버 PC의 방화벽에서 해당 포트(기본 1234)를 허용해야 합니다.
