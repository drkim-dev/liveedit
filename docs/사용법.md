# LiveEdit 사용법 (팀원용)

Obsidian 노트를 팀원들과 노션처럼 실시간으로 같이 보고 편집하는 플러그인입니다.
아래 순서대로만 따라 하시면 됩니다.

먼저 내가 **방장**인지 **참여자**인지 확인하세요.

- **방장**: 릴레이 서버(`server/`)를 자기 PC에서 실행해두고, Obsidian도 계속 켜서
  다른 팀원과 같이 편집하는 사람. 보통 팀에 한 명(또는 상시 켜진 PC 담당자)입니다.
- **참여자**: 방장이 켜둔 서버 주소로 접속만 하는 사람. 서버를 따로 실행할 필요 없습니다.

## 1. BRAT 설치

1. Obsidian 설정 → **커뮤니티 플러그인** → 찾아보기
2. `BRAT` 검색 (정식 이름: *Obsidian42 - BRAT*) → 설치 → 활성화

## 2. LiveEdit 추가

1. Obsidian 설정 왼쪽 메뉴에서 **BRAT** 클릭
2. **Add Beta plugin** 버튼 클릭
3. 저장소 주소 입력란에 아래 값을 입력 (관리자에게 정확한 아이디 확인)

   ```
   <깃허브아이디>/liveedit
   ```

4. Add Plugin 클릭 → 설치 완료되면 알림이 뜸
5. 설정 → 커뮤니티 플러그인 목록에서 **LiveEdit** 켜기

## 3. 최초 설정 (한 번만)

Obsidian 설정 → **LiveEdit** 탭으로 이동합니다.

### 내가 방장이라면

1. **이 PC의 역할** → `방장 (릴레이 서버 운영)` 선택
2. 관리자 문서(README)를 참고해서 `server/` 폴더의 릴레이 서버를 이 PC에서 먼저 실행
3. **릴레이 서버 주소**에 `ws://localhost:포트` 입력 (기본 포트 1234면 `ws://localhost:1234`)
4. 옆에 생기는 **서버 상태 확인** 버튼을 눌러서 정상 동작하는지 확인
5. 팀원들에게 이 PC의 사설망 IP + 포트(예: `ws://192.168.0.10:1234`)와 방 코드를 알려주기

### 내가 참여자라면

1. **이 PC의 역할** → `참여자` 선택 (기본값)
2. 아래 값을 방장에게 전달받은 대로 입력

| 항목 | 무엇을 넣나요 |
|---|---|
| 릴레이 서버 주소 | 방장이 알려준 주소 (예: `ws://192.168.0.10:1234`) |
| 방 코드 | 팀에서 같이 쓰기로 한 코드 (같은 코드를 쓰는 사람끼리만 공유됨) |

### 공통 설정

| 항목 | 무엇을 넣나요 |
|---|---|
| 표시 이름 | 다른 팀원에게 보여질 내 이름 |
| 커서 색상 | 원하는 색으로 자유롭게 |
| 공유 폴더 | 보통 비워두면 됨 (vault 전체 공유). 특정 폴더만 공유하고 싶으면 관리자에게 폴더명 확인 |
| 자동 재연결 | 켜두면 Obsidian 켤 때마다 자동으로 접속됨 (추천) |

이 화면을 벗어나면 자동으로 저장됩니다.

> ⚠️ 연결되어 있는 도중에 **서버 주소나 방 코드를 바꾸면 자동으로 연결이 끊깁니다.**
> (예전 방에 계속 붙어있는 채로 헷갈리는 걸 막기 위한 의도된 동작입니다.) 바꾼 뒤에는
> `LiveEdit: 세션 연결`로 다시 접속해주세요.

## 4. 사용하기

Ctrl/Cmd + P로 명령 팔레트를 열고 아래 명령을 검색해서 씁니다.

- **LiveEdit: 세션 연결** — 팀과 연결 시작
- **LiveEdit: 세션 연결 해제** — 연결 끊기
- **LiveEdit: 참여자 보기** — 지금 접속 중인 팀원 목록 확인
- **LiveEdit: 서버 상태 확인 (방장용)** — 방장만 신경 쓰면 되는 명령. 내 서버가 살아있는지 확인

화면 아래쪽 상태바에 `🟢 LiveEdit(방장) · N명` 또는 `🟢 LiveEdit(참여자) · N명`이라고
뜨면 정상 연결된 것이고, 클릭하면 참여자 목록도 바로 볼 수 있습니다.

연결된 상태에서:
- 같은 노트를 팀원과 동시에 열면 타이핑하는 대로 실시간으로 서로 보입니다.
- 새 노트를 만들거나 지우면 팀원 vault에도 그대로 반영됩니다.
- 지금 보고 있지 않은 노트도 팀원이 수정하면 백그라운드에서 자동으로 최신 내용으로 갱신됩니다.
- "방장"이라고 해서 그 사람 내용이 더 우선시되는 건 아닙니다 — 누가 서버를 켜두고
  있느냐만 다를 뿐, 문서 병합 자체는 모두 동등합니다.

## 알아두면 좋은 점

- 이미지 등 첨부파일과 캔버스(`.canvas`)는 실시간 동기화 대상이 아닙니다. `.md` 노트만 동기화됩니다.
- 노트 이름을 바꾸면 "삭제 후 새로 생성"되는 방식으로 처리됩니다.
- 연결을 껐다가 다시 켰을 때, 이미 열려 있던 노트는 한 번 닫았다 다시 열어야 실시간 편집이 바로 적용됩니다.
- 방장의 서버가 꺼져 있으면 아무도 접속할 수 없습니다. 잘 안 될 때는 방장에게
  **서버 상태 확인** 버튼(또는 명령)으로 먼저 확인해달라고 요청하세요.
- 상태바가 `⚪ LiveEdit 연결 안 됨` 또는 `🟡 연결 중…`에 멈춰 있으면 서버 주소/방
  코드가 정확한지 확인하세요.
