# LiveEdit 빠른 사용법

## 방장

1. 서버 PC에서 `start.cmd`를 더블클릭합니다.
2. 같은 PC의 Obsidian → 설정 → LiveEdit → **방장**을 선택합니다.
3. 기본 서버 주소 `ws://localhost:1234`에서 **방 개설하기**를 누릅니다.
4. 팀원에게 `ws://서버PC사설IP:1234`를 알려줍니다.

## 참여자

1. 설정 → LiveEdit → **참여자**를 선택합니다.
2. 방장이 알려준 서버 주소를 입력합니다.
3. **참여하기**를 누릅니다.

최신 노트를 다 받으면 편집할 수 있습니다. 끊기면 읽기 전용이며 재접속 후 다시 편집할 수 있습니다.
공유 대상은 현재 볼트 전체입니다. 개인 노트는 다른 볼트를 사용하세요.
방 코드·인증 키·공유 폴더는 입력하지 않습니다.

- 접속 전 이름을 입력하세요. 색상은 자동 배정됩니다.
- 왼쪽 파일 목록에서 노트 이름 옆에 그 노트를 열어둔 사람의 이름과 색상이 표시됩니다. 작성 중/보는 중은 구분하지 않습니다.
- 사진 공유를 위해 방장·참여자 플러그인과 서버 모두 0.8.0으로 업데이트합니다.

- 폴더를 접으면 안쪽 노트를 열어둔 사람들을 폴더 옆에 모아 표시합니다. 펼치면 노트 옆에 표시됩니다.

- 폴더 생성·삭제·이름 변경도 연동됩니다. 공유하지 않는 첨부파일·숨김 파일이 들어 있는 폴더는 보호를 위해 남깁니다.

- 누구든 노트에 사진을 붙여넣거나 드래그하면 다른 사람에게도 사진 파일이 자동으로 전달됩니다. 같은 경로에 저장하므로 사진 링크도 유지됩니다.
- 사진은 한 장 20MB, 방 전체 64MB까지 공유합니다. PDF와 캔버스는 공유하지 않습니다.
