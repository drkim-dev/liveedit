# LiveEdit 0.5.0 서버 실행

이 압축파일에는 빌드된 서버(`dist/`)가 들어 있습니다. Node.js 20 이상이 필요합니다.

1. 항상 사용할 서버 폴더에 압축을 풉니다.
2. 그 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.

```powershell
npm ci --omit=dev
$env:PORT = "1234"
$env:LIVEEDIT_TOKEN = "팀원에게-공유할-긴-랜덤값으로-변경"
$env:LIVEEDIT_HOST_TOKEN = "방장만-보관할-다른-긴-랜덤값으로-변경"
$env:LIVEEDIT_DATA_DIR = Join-Path $PWD "data"
node dist/server.js
```

팀원은 플러그인에 `ws://서버사설IP:1234?token=팀접속토큰`을 입력합니다.
방장은 같은 접속 주소를 사용하면서 역할을 **방장**으로 지정하고 **방장 인증 키**에
`LIVEEDIT_HOST_TOKEN`과 동일한 값을 입력합니다. 새 방에는 방장이 먼저 연결하세요.

방장 키는 팀 접속 토큰과 달라야 하며, 이 서버의 모든 방에 대한 관리 권한을 줍니다.
서버와 모든 클라이언트 플러그인을 함께 0.5.0으로 업데이트하세요. 이전 플러그인의 접속은 거절됩니다.
기존 `data/` 폴더의 방 상태는 유지해서 사용할 수 있습니다.

`data/`는 방 상태 저장소입니다. 기존 서버를 업데이트할 때 그대로 보존하고,
서버를 재시작할 때도 같은 폴더와 같은 토큰을 사용하세요. 마지막 저장 이후 약 300ms의
변경분은 갑작스러운 종료 시 유실될 수 있습니다.

이 창을 닫으면 서버도 종료됩니다. 상태 확인 주소는 `http://서버사설IP:1234/healthz`입니다.
신규 입장 잠금은 기존 접속자의 재접속도 막으며, 서버 재시작 또는 빈 방 정리 후 해제됩니다.
퇴장은 현재 연결을 종료하고 자동 재접속을 중단시키는 기능이며 영구 차단은 아닙니다.
