# LiveEdit 0.6.0 서버

1. Node.js 20 이상이 설치된 PC에 이 ZIP을 풉니다.
2. 기존 서버 창을 닫습니다. 기존 `data` 폴더는 이 폴더에 보관합니다.
3. `start.cmd`를 더블클릭합니다. 서버 창을 닫지 마세요.
4. 같은 PC의 Obsidian에서 방장 → 방 개설하기를 누릅니다.

방장은 기본 주소 `ws://localhost:1234`를 사용합니다.
참여자는 `ws://서버PC사설IP:1234`로 참여합니다.
서버 PC의 방화벽에서 해당 포트(기본 1234)를 허용해야 합니다.

방 개설 권한은 실제 접속한 PC가 서버 PC인지 확인해 부여합니다.
방 코드나 방장 인증 키를 새로 설정할 필요가 없습니다.
서버 0.6.0과 플러그인 0.6.0을 함께 사용하세요.
